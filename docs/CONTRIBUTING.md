# Guide de contribution à MUM

Merci pour votre intérêt à contribuer au projet **MUM** !

## 📜 Principes directeurs

1. **Licence non-commerciale** : Toute contribution est soumise aux termes de la [PolyForm Noncommercial License 1.0.0](LICENSE).
2. **Confidentialité & Données** : Aucun fichier de données personnelles, photo, base SQLite ou clé secrète/token ne doit jamais être commité.
3. **Nomenclature & Standard** :
   - Dates au format ISO 8601 (`AAAA-MM-JJ`).
   - Nommage des fichiers en minuscules / snake_case ou kebab-case.
   - Code Python conforme à la PEP 8.

## 🛠️ Processus de contribution

1. Forkez le projet.
2. Créez votre branche de fonctionnalité (`git checkout -b feat/nom-fonctionnalite`).
3. Effectuez vos modifications et assurez-vous que les tests / syntaxe sont validés.
4. Commitez vos modifications avec des messages clairs (norme *Conventional Commits* : `feat: ...`, `fix: ...`, `docs: ...`).
5. Poussez votre branche (`git push origin feat/nom-fonctionnalite`).
6. Ouvrez une Pull Request.
